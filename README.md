# mle-analiz-loyalnosti-polzovatelej
# Анализ лояльности пользователей Яндекс Афиши

Итоговый проект модуля 2, спринта 7 курса «Инженер машинного обучения» Яндекс Практикума. Цель исследования — выяснить, какие характеристики первого заказа связаны с повторными покупками билетов.

`main.py` запускает анализ и печатает отчёт в терминале. Класс `DataProcessor` объединяет локальные выгрузки, чистит данные, строит профили пользователей и проверяет гипотезы. [Описание модуля обработки](src/README.md)

## Запуск

Для проекта использовался Python 3.13. В папку `data/` в корне репозитория положите учебные выгрузки `purchases_*.csv`, `events_*.csv`, `city_*.csv`, `regions_*.csv` и файл `final_tickets_tenge_df.csv`. [Скачать файл курсов](https://code.s3.yandex.net/datasets/final_tickets_tenge_df.csv)

Выполните из корня проекта в терминале macOS или Linux.

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Выводы исследования

В ноутбуке исследовались заказы за июнь–октябрь 2024 года с мобильных устройств и компьютеров, за исключением заказов на кино. Выручку в тенге перевели в рубли по курсу на дату заказа. Удалили 40 подтверждённых дублей и 2 825 заказов выше 99-го перцентиля выручки. Исключили 16 профилей с отрицательной средней выручкой и 216 сверхактивных аккаунтов.

После очистки осталось **21 622 пользователя** и **140 629 заказов**. Два заказа или больше сделали **61,34%** пользователей. Средняя выручка сервиса с заказа составила **522,29 ₽**.

| Заказов у пользователя | Пользователей |
| --- | ---: |
| 1 | 8 358 |
| 2 | 3 568 |
| 3–4 | 3 575 |
| 5 и более | 6 121 |

- **Тип мероприятия.** Гипотеза о более высокой доле возвратов после первого заказа на спорт не подтвердилась. Повторно купили 55,79% пользователей после спорта и 61,83% после концертов.
- **Устройство и регион.** После первого заказа с компьютера вернулись 63,81% пользователей, с мобильного устройства — 60,83%. В трёх регионах с наибольшим числом пользователей доля составила 63,06%, в остальных — 59,18%. Для регионального сравнения значение p после поправки Холма — 6,9 × 10⁻⁹.
- **День недели.** Размах долей повторных покупок по дням недели составил 3,62 п.п. Сила связи мала, V Крамера — 0,029.
- **Корреляции.** Среди проверенных признаков первого заказа самая сильная связь с группой числа заказов наблюдалась у региона мероприятия (ΦK = 0,098). Интервал между первой и последней покупкой (ΦK = 0,706) и среднее число билетов (ΦK = 0,535) описывают всю историю заказов и включают сведения о последующих покупках.

Первый заказ в анализе — первый заказ пользователя после фильтрации. Регион относится к мероприятию. Доли повторных покупок рассчитаны за доступный период наблюдения, поэтому у поздних когорт было меньше времени на повторный заказ.

## Бизнес-рекомендации

- В крупных сегментах проверить через A/B-тесты, повышают ли персональные рекомендации и упрощение повторного заказа долю возвратов.
- Изучить повторную покупку на мобильных устройствах и в регионах с низкой долей возвратов. Приоритизировать изменения по размеру сегментов и экономике.
- Сравнивать когорты по доле повторных покупок за 30 дней среди пользователей с полным окном наблюдения.
- Вместе с владельцем данных разобраться в причинах отрицательной выручки и проверить спорные пары заказов с разным числом билетов.
