

В `processing.py` находится класс `DataProcessor`. Он загружает и объединяет CSV, очищает заказы, строит профили пользователей и рассчитывает показатели повторных покупок. Класс используется в `main.py` для подготовки отчёта.

Описание проекта, инструкция по запуску и выводы исследования приведены в [корневом README](../README.md).
